Task 1:CNN model to classify images into predefined categories.

PROJECT OVERVIEW:

This project is an image classification system built using a Convolutional Neural Network (CNN). The model is trained using the CIFAR-10 dataset and can identify different types of images such as airplanes, cats, dogs, trucks, ships, and more.

The project includes:

Image preprocessing
Data augmentation
CNN model training
Model evaluation
Prediction on custom images

DATASET INFORMATION:

Dataset Name: CIFAR-10
Source: TensorFlow / CIFAR Dataset (Other)
Dataset Link: CIFAR-10 Dataset
Dataset Type: Image Classification Dataset
Number of Records Used: 60,000 images
Number of Classes: 10
Class Names: Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, Truck

FEATURES OF THE PROJECT:

Image normalization
Data augmentation
CNN-based image classification
Evaluation metrics
Confusion matrix visualization
Prediction on multiple custom images
Trained model saving
